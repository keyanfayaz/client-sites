## How this space works

- **Every page has an owner.** Named at the bottom, with a review date. No orphan documents.
- **Reviewed quarterly.** Anything past its review date shows as stale and gets picked up in the owning team's planning.
- **Changes go through pull request.** Content lives as Markdown in version control, so every edit is reviewable and revertible.
- **If it is not written down, it is not policy.** Verbal guidance does not survive staff turnover.

Found something wrong? Raise it with the page owner or open a pull request against the content repository.
