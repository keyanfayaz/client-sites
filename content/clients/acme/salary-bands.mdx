# Salary Bands

This page exists to demonstrate `published: false`.

It is filtered out in `src/lib/clientPages.ts` at the point pages are loaded, so
it does not appear in the navigation and requesting `/salary-bands` returns a 404
like any other unknown path. Flip `published` to `true` and it appears in both.

That filtering governs what the site **serves**, not what the repository
**contains**. This file is still readable by anyone who can read the repo, so it
is not a way to keep sensitive content secret — it is a drafting workflow.
